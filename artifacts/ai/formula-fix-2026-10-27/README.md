# Q5-FORMULA-01: геометрия формул — 27.10.2026

База исправления: AI 205e740, без изменения человеческих оценок и без PR.

## Что изменено

`backend/pdf_math.py` читает позиции реальных glyphs и горизонтальных линий PDF через имеющийся PyMuPDF. Верхние/нижние индексы, дробные черты и корни превращаются в явную запись `^{...}`, `_{...}`, `\frac{...}{...}`, `\sqrt[n]{...}`. Встроенной таблицы математических тождеств или распознавания по хешу файла нет. Нормализованный текст — единый источник страницы для модели и строгого guard; проверка цитат не отключена.

`backend/pdf_extractor.py` использует новый путь для страниц с преобладанием математики и помечает их `method=math_layout`. Проза, страницы с менее чем тремя знаками равенства, чрезмерно плотные страницы и недоступная геометрия сохраняют предыдущий путь. OCR не менялся. Это ограниченный геометрический extractor, а не универсальная математическая OCR-модель.

Генератор разделяет строки `$...=...$` на самостоятельные тезисы и сохраняет короткую формулу a^0=1. При повторной загрузке математического PDF идентичность документа включает структурированный текст: старый плоский результат не переиспользуется и не вызывает конфликт 409; обычные PDF сохраняют прежнюю идентичность.
