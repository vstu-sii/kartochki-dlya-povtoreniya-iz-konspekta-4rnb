# UI-прототип

`index.html` — автономный as-code прототип без сборки. Шесть экранов покрывают UC-01…UC-05: загрузка PDF, ответ, оценка полезности, итог сессии, продолжение, отказ скана без текста.

Локальный просмотр:

```bash
python -m http.server 8080 --directory frontend/prototype
```
