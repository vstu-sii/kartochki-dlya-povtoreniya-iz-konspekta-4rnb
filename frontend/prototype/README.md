# UI-прототип Telegram-бота

`index.html` — автономный as-code прототип переписки с Telegram-ботом. Это не отдельный веб-фронтенд и не Telegram Mini App: страница используется как визуальный storyboard интерфейса бота.

Шесть состояний чата покрывают UC-01…UC-05:

- отправка PDF как вложения и статус обработки;
- вопрос бота и текстовый ответ пользователя;
- разбор ответа с цитатой из источника и inline-кнопками;
- итог завершённой сессии;
- продолжение незавершённой сессии;
- отказ PDF без текстового слоя до вызова модели.

Локальный просмотр:

```bash
python -m http.server 8080 --directory frontend/prototype
```

Откройте `http://localhost:8080`. Скриншот ключевых состояний хранится в `screenshots/key-screens.png`.
