# Рабочий интерфейс Lab 3

Это Telegram-подобный web-клиент для проверки сквозного MVP, а не отдельная продуктовая концепция. Он вызывает Application API, показывает loading/error states, пять карточек, citation и результат проверки ответа.

В Compose nginx проксирует `/api/*` в backend. Отдельный `python -m http.server` показывает только разметку и не даёт сквозного сценария; для проверки используйте команду из корневого README.
