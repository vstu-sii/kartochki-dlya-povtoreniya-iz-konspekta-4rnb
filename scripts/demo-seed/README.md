# Демо-данные Lab 6

Одна команда очищает и заново создаёт **только** выделенный набор
`demo_lab6_*` и пользователя `demo_lab6_student`:

```bash
python scripts/demo-seed/reset_demo.py
```

Команду можно повторять: после каждого запуска остаются ровно пять карточек,
одна незавершённая учебная сессия и одна оценка. Реальные пользовательские
документы и сессии не выбираются и не удаляются.

Локально используется `DATABASE_URL` из окружения либо стандартная SQLite-БД.
Для production команду запускает Delivery в Render Shell, где `DATABASE_URL`
уже задан секретом. Значение URI базы в Git не сохраняется.
