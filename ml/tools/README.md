# Контракт инструмента `lookup_source`

Инструмент даёт модели только чтение фрагментов уже загруженного пользователем документа.

## Вход

- `user_id` и `resource_owner_id` — непустые и равные;
- `query` — строка поиска;
- `pages` — список `{page: int, text: string}`;
- `max_results` — от 1 до 5.

## Выход

`SourceLookupResult(status, passages)`, где каждый passage содержит только `page` и ограниченный `text`.

## Права и отказ

- Нет записи в БД, сети, файловой системы и необратимых действий.
- Чужой ресурс возвращает `tool_forbidden` без содержимого.
- Таймаут по умолчанию 1 секунда порождает `ToolTimeout`; baseline использует безопасный контекст исходного запроса и пишет `tool_status=timeout_fallback_to_request_pages` в trace.
- Дополнительное действие, придуманное моделью, отсутствует в API инструмента и не исполняется.
