# Проверка безопасности демо

Статус: повторный прогон на демо-теге не выполнен. До выступления проверить инструкции внутри PDF и ответа студента: попытки раскрыть системные инструкции, игнорировать правила, выдать неподтверждённую цитату и выполнить внешнее действие. Записать вход, SHA, результат, ошибку и ссылку на тест; не использовать реальные секреты. Ненадёжные сценарии оформить задачами и повторно проверить исправления.

Q&A: модель предлагает содержание, а приложение проверяет формат и цитаты; информация из загруженного файла не становится инструкцией для изменения прав. Ошибки возможны; исходные материалы и метрики с ограничениями доступны в отчёте Lab5.
