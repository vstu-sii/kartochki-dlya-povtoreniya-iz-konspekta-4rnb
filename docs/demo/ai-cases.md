# Демо-кейсы AI

1. PDF с понятиями: студент получает вопрос и сверяет цитату с документом.
2. Ответ своими словами: студент объясняет понятие, не копируя эталон.
3. Неполный ответ: бот указывает недостающие пункты.
4. PDF с математикой: проверяем символы и формулы по оригиналу.
5. Ограничение: скан, некорректная формула в источнике или медленный ответ; приложение не гарантирует математическую истинность текста PDF.

Повторяемость всех кейсов на окончательном демо-теге пока не подтверждена. Для каждого прогона записывать время, SHA, вход, результат, модель и fallback; не помещать секреты и чужие PDF в репозиторий без согласия.
