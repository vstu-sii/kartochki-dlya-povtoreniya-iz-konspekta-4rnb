# Шпаргалка Q&A

- **Как измеряли качество?** На живом поднаборе Lab5 согласие с исходным эталоном составило 36/42; после пересмотра трёх спорных эталонов те же ответы дали 39/42. Это не новый вызов модели.

- **Что происходит с инструкцией внутри PDF?** Текст документа считается недоверенным содержимым. Повторный red-team на окончательном демо-теге ещё требуется.
- **Почему ответ иногда долгий?** Зависимость от модели и сети; последний публичный p95 31,990 с по пяти ответам, выборка мала.
- **Что делает команда при отказе?** Показать понятное сообщение или резервный сценарий; локальная проверка fallback не заменяет репетицию в Telegram.
