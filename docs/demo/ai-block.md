# Как работает AI: объяснение для Demo Day

Студент загружает PDF. Приложение извлекает из него текст и передаёт подходящий фрагмент модели Gemini. Модель предлагает вопросы, ответы и цитаты; приложение проверяет структуру и соответствие цитат документу, а затем сохраняет карточки. При ответе студента модель сравнивает смысл с эталоном и возвращает обратную связь. Проверки не гарантируют отсутствие ошибок: студент может сверить карточку с источником.

На наблюдавшемся прогоне Lab5 исходный live golden дал 36/42 совпадений для оценок (85,71%). После согласованного пересмотра трёх эталонов на тех же ответах — 39/42 (92,86%). Это не повторный запуск модели. Офлайн-прогон исправленной рубрики на сохранённых ответах — 42/42, тоже не новое измерение Gemini. Источник: `docs/quality/live-provider-verification-2026-10-28.md` в ветке Quality.

Финальную динамику и вклад изменений брать из измерений ablation в документах Lab5; сравнивать только совпадающие наборы и версии. Последний публичный p95 проверки ответа — 31,990 с на пяти запросах, цель ≤7 с не достигнута. Старый p95 6,965 с на десяти запросах не подтверждает стабильность.
