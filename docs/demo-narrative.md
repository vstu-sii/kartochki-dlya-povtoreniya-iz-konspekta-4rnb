## Каркас (боль → решение → цифры)

1. **Боль.** Из длинного PDF трудно сделать вопросы и проверить ответ своими словами (PRD, `docs/acceptance.md`).
2. **Сценарий.** Публичный Telegram: PDF → 5 grounded-карточек → ответ → разбор → сессия в БД.
3. **Доказательство системы.** 132/132 golden, 37/37 application, schema/grounding 100%. Публичный smoke: `artifacts/product/lab5-prod-uc.json`.
4. **Почему эта AI-версия.** Prompt B 100% vs 95% на 20 кейсах Gemini. Deterministic review Lab5 92,86% при пороге 85%; ablation без смысловых правил — 88,10%, lexical — 71,43%.
5. **Доверие.** 17/17 **успешных** security-проверок: 14 block + 2 allow (safe-control) + 1 auth deny. Не «17/17 заблокированы».
6. **North Star.** Цель ≥70% внешних сессий с `current_position ≥ 5`. Факт: Постернак Денис **1/1 = 100%**. n=1, для подтверждения нужно ≥10.
7. **Ограничения.** Один PDF; OCR скана не обещан; `X-User-ID` ≠ auth; латентность Gemini нестабильна; фриз прода объявляет Delivery за сутки до даты.
