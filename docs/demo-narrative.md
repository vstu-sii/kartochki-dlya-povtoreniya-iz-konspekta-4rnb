# Нарратив Demo Day

1. **Боль.** Из длинного PDF трудно быстро сделать вопросы и понять, верен ли свободный ответ.
2. **Сценарий.** Загружаем PDF в Telegram, получаем пять grounded-карточек, отвечаем своими словами, видим вердикт и цитату, продолжаем с сохранённого места.
3. **Доказательство системы.** UI → API → модель → БД проходит E2E; grounding и schema — 100% на frozen dataset; полный Quality-набор покрывает 132/132 кейса.
4. **Почему эта AI-версия.** Реальный Gemini A/B: prompt B — 100% против 95% у A на 20 кейсах, цена 6380 против 3843 токенов. После точечной Lab5-правки deterministic review — 92,86% против 90,48% ранее и выше порога 85%; fallback сохранён.
5. **Надёжность и безопасность.** Временный отказ модели и БД превращается в штатный 503, атаки повторно прогоняются, необратимые действия остаются у приложения.
6. **Пользовательский результат.** North Star — ≥70% сессий с пятью завершёнными карточками. Текущий внешний замер 1/1, но n=1 недостаточно; до демо приоритет — минимум 10 внешних сессий.
7. **Ограничения.** Один PDF, OCR зависит от скана, Gemini A/B мал, полноценная auth/Redis нужны перед продажей.

Финал: концепция технически доказана и измеряется; следующий риск — повторяется ли пользовательская ценность на достаточной выборке.
