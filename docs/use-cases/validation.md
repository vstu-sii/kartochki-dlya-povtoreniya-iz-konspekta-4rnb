# Проживаемость use cases

## Что это значит

«Прожить UC» — дать человеку **не из команды** только UI-прототип и один демо-PDF, попросить пройти сценарии **без объяснений** и записать, где он остановился или задал вопрос. Если человек проходит все шаги сам — UC проживаем; если спрашивает «куда нажать?» — формулировка или интерфейс плохие.

## Протокол

Проверяющий — студент другой команды курса, документы проекта не читал. Дана ссылка на `frontend/prototype/index.html` и демо-PDF с текстовым слоем (`demo_os_cache.pdf`, 4 стр.). Наблюдатель (Product) молчит, фиксирует таблицу.

Задания без подсказок:

1. понять, как создать карточки из PDF;
2. ответить на вопрос и объяснить, что означает вердикт;
3. отметить карточку как неполезную;
4. найти итог сессии и способ продолжить позже;
5. понять, что делать, если загружен скан без текста.
