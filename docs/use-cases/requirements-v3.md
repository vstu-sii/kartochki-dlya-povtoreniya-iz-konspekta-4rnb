# Use cases v3 после production-итерации

Базовые шаги UC-01…UC-05 из `README.md` сохраняются. Ниже перечислены явные изменения.

| UC | Изменение v3 | Проверяемый результат |
|---|---|---|
| UC-01 Загрузить PDF | До генерации проверяются тип, размер, страницы, injection и суточный бюджет | Небезопасный ввод получает стабильный код; данные не передаются модели |
| UC-02 Получить карточки | Повторный запрос кэшируется; после 80% бюджета выбирается cheap tier | Нет дубликата и повторной стоимости; ответ сообщает фактическую модель |
| UC-03 Ответить своими словами | Проверка использует только каноническую карточку из БД | Клиент не может подменить эталонный ответ |
| UC-04 Продолжить сессию | Доступ проверяется по владельцу и сроку 30 дней | Чужая сессия возвращает 403, устаревшая — 410 |
| UC-05 Оценить карточку | Модель не может сама записать рейтинг или завершить сессию | Изменение выполняет только авторизованный endpoint приложения |
| UC-06 Достичь лимита | На 80% включается дешёвая модель, на 100% запрос отклоняется | Срабатывание видно в логах, `/metrics` и Grafana |
| UC-07 Недоступен model tool | Таймаут не раскрывает данные и не зависает | Генерация использует безопасный исходный контекст или возвращает контролируемую ошибку |

Версия требований: 3.0, 16.10.2026. Контракты API остаются обратно совместимыми с лабораторной 3.
