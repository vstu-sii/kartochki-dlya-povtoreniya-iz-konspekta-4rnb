# Use cases v3 после production-итерации

Канон сценариев — `README.md` (UC-01…UC-07). Ниже — **явные дельты** относительно Lab 3 / `requirements-v2.md`. Нумерация UC не менялась.

| UC | Изменение v3 | Проверяемый результат |
|---|---|---|
| UC-01 Создать карточки из PDF | До генерации: тип, размер, страницы, injection, суточный бюджет; кэш повторного запроса; после 80% бюджета — cheap tier | Небезопасный ввод не доходит до модели; нет дубликата стоимости; в ответе/telemetry видна фактическая модель |
| UC-02 Раунд вопрос–ответ | Проверка использует только каноническую карточку из БД | Клиент не подменяет эталон |
| UC-03 Оценить полезность | Модель не пишет рейтинг и не завершает сессию; пишет только авторизованный endpoint | Изменение рейтинга только через приложение |
| UC-04 Завершить / возобновить | Владелец + TTL 30 дней | Чужая сессия → 403; просроченная → 410 |
| UC-05 Отклонить документ | Guards усилены под security-набор Lab 4 | Известные injection из набора блокируются кодом |
| UC-06 Достичь лимита *(новый)* | 80% → дешёвая модель; 100% → отказ | Видно в логах, `/metrics`, Grafana |
| UC-07 Недоступен model tool *(новый)* | Таймаут/отказ инструмента обработан приложением | Нет зависания и утечки данных |

## North Star (уточнено в `docs/prd.md`)

Не менее **70%** начатых учебных сессий завершаются минимум по **пяти** карточкам. Защитные метрики: schema/grounding 100%, review agreement ≥85%, непонятные ошибки &lt;2%.
