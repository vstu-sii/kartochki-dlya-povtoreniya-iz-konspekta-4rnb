# Требования v2 после встречи с прототипом

Изменения относительно `docs/use-cases/README.md` отмечены явно.

## Изменено

- **UC-01:** Telegram принимает один PDF до 10 МБ; API сначала читает текстовый слой, а для сканированных страниц применяет OCR. Неразборчивый, зашифрованный или превышающий лимиты PDF получает стабильный код ошибки до вызова модели.
- **UC-01:** при недостатке независимых тезисов набор может содержать меньше пяти карточек вместо повторения одной формулировки. UI объясняет причину.
- **UC-02:** короткий ответ нельзя считать неверным только из-за малого лексического пересечения; verdict `incorrect` требует подтверждённого противоречия или отсутствия ключевого тезиса.
- **UC-02:** feedback обязательно показывает, какой пункт эталона отсутствует, но не раскрывает весь эталон до завершения попытки.
- **UC-03:** повторная оценка атомарно заменяет текущее значение пары session/card, а каждое изменение отдельно сохраняется в `card_rating_events`. Агрегированный отчёт истории остаётся расширением после MVP.
- **UC-04:** resume открывает первую непройденную карточку после перезапуска Web/Telegram. Сессия старше 30 дней считается просроченной и не открывается; физическая фоновая очистка записей остаётся задачей следующего спринта.
- **UC-05:** prompt injection в материале не исполняется; карточка всё равно обязана иметь дословную цитату из страницы.

## Не изменено

Лимиты 40 страниц / 60 000 оценочных токенов, запрос 5–10 карточек, фактически 1–10 при недостатке независимых тезисов, p95 генерации 60 секунд, p95 review 7 секунд и запрет на чужие сведения остаются критериями целевого MVP. Лимит файла уточнён с 20 до 10 МБ, чтобы совпадать с реализованной защитой API и Telegram-адаптера.


Уточнение 15.10.2026: OCR, история рейтингов и проверка срока сессии уже реализованы Delivery. Проверка владельца по X-User-ID пока не является серверной аутентификацией; полноценная защита чужих данных остаётся открытой задачей Delivery. Автоматическая техническая проверка описана в `../quality/verification-2026-10-15.md`; внешний ручной проход остаётся отдельным условием приёмки.
