|---|---|---|---|---|
| YandexGPT Pro 5.1 | облачная, РФ | данные хранятся в РФ, хороший русский язык, недорого, простой API | качество рассуждений уступает топовым западным моделям | около 0.8 рубля (input и output вместе, по прайсу AI Studio на июль 2026) |

## Выбор на лабу 1

Берём **YandexGPT Pro 5.1** как основного кандидата: данные студентов (конспекты) остаются в РФ, что важно раз речь о персональных учебных материалах, цена ниже GigaChat Pro, есть удобный SDK. GigaChat держим как запасной вариант, если понадобится сравнить качество вопросов на реальных методичках. Локальную модель не берём на лабу 1, чтобы не тратить время на настройку железа раньше времени, вернёмся к варианту если у команды не будет бюджета на облачный API.

## Расчёт стоимости одного сценария

Сценарий: загрузка PDF методички (15 страниц, примерно 15000 токенов текста), плюс генерация 5-10 вопросов (примерно 1000 токенов на выходе), плюс разбор 5-10 устных ответов пользователя (каждый ответ и разбор это примерно 300 токенов на вход и 200 на выход, итого около 2500 токенов на всю сессию разборов).

Итого на одну сессию: примерно 15000 (текст методички) + 1000 (вопросы) + 2500 (разборы ответов) = 18500 токенов.

По цене YandexGPT Pro 5.1 (0.8 рубля за 1000 токенов): 18500 / 1000 * 0.8 = около 15 рублей за одну полную сессию подготовки к защите одной лабы. Это разумная цена, укладывается в North Star из PRD.

## Что меняется, если модель придётся держать локально

Если по каким то причинам нельзя отправлять конспекты во внешний API (например требование вуза не выгружать методички в облако), придётся переходить на локальную модель типа Qwen 7B. Тогда:

- Нужен сервер или у кого то в команде мощная видеокарта (минимум 8-12 GB VRAM для модели уровня 7B в квантовании Q4)
- Качество извлечения тезисов вероятно просядет, локальные модели такого размера хуже топовых облачных на задачах вроде выделения главного из текста
- Деплой усложняется, каждому пользователю бота придётся либо ставить модель себе, либо команда держит один сервер с GPU для всех, что дороже по железу чем облачный API при небольшом числе пользователей

## Лимиты и деградация

Когда бюджет токенов на сессию или на день исчерпан, бот присылает сообщение "Дневной лимит запросов исчерпан, попробуй завтра" вместо тихого зависания или непонятной ошибки. На лабу 1 это просто зафиксированное поведение в документе, реализация появится когда будет код бота.
