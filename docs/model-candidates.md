# Кандидаты моделей и токен-бюджет

## Кандидаты

Актуализация исследования выполнена 6 сентября 2026 года. Критерии выбора для лабы 1: бесплатный доступ, качество на русском языке и задачах по учебным текстам, работа с длинным контекстом/PDF, структурированный вывод для генерации вопросов и разборов, простота интеграции и приватность данных.

| Кандидат | Тип | Плюсы | Минусы | Цена за 1000 токенов |
|---|---|---|---|---|
| **Qwen3.8 27B локально** | локальная, open-weight | бесплатно после установки, данные не покидают компьютер, открытые веса, подходит для research/проф. задач, поддерживает структурированный вывод и tool use через совместимые рантаймы | нужен локальный запуск и достаточно мощное железо; качество/скорость зависят от квантования и железа; для команды сложнее, чем облачный API | **0 рублей** |
| **Gemini 3.8 Flash** | облачная, Google AI Studio | бесплатный input/output на Free tier, 1M токенов контекста, принимает PDF, поддерживает thinking, structured outputs, file search и function calling; GA и актуальная стабильная Flash-модель | в Free tier Google может использовать контент для улучшения продуктов; лимиты зависят от проекта/модели и фактическая ёмкость не гарантируется | **0 рублей** в Free tier |
| **GPT-OSS 120B через Groq** | облачная, open-weight | очень высокая скорость (~500 токенов/с), reasoning, JSON Schema/structured outputs, tool use; бесплатный план даёт 200K токенов/день и 1K запросов/день | лимит 8K токенов/мин требует разбивать длинную методичку на части; данные уходят во внешний API; нужен API key | **0 рублей** в Free plan |
| **MiniMax M3 через OpenRouter** | облачная, OpenRouter free | бесплатный endpoint, 1M контекст, multimodal input, tool calling и structured JSON; OpenRouter даёт единый API и автоматический failover между провайдерами | бесплатный пул rate-limited; у OpenRouter Free-плана сейчас лимит 50 запросов/день; политика хранения/обработки зависит от выбранного провайдера | **0 рублей** |

## Выбор на лабу 1

Берём **Qwen3.8 27B локально** как основной бесплатный кандидат, если сохраняется исходное требование не отправлять студенческие конспекты и методички во внешний API. Модель выпущена 14 августа 2026 года; официальный репозиторий публикует веса и поддерживает запуск через SGLang/vLLM с OpenAI-совместимым API. Это лучше соответствует исходному требованию приватности, чем бесплатные облачные варианты.

Для команды без подходящего железа берём **Gemini 3.8 Flash** как основной облачный fallback: на Free tier входные и выходные токены бесплатны, модель принимает PDF, имеет контекст до 1 048 576 токенов и поддерживает structured outputs. При этом важно учитывать, что Google указывает использование контента Free tier для улучшения продуктов, поэтому такой вариант нельзя считать эквивалентом локального по приватности.

**GPT-OSS 120B через Groq** держим как второй облачный fallback, прежде всего когда важны скорость и рассуждение. Его бесплатные лимиты подходят для небольшого бота, но длинную методичку придётся обрабатывать чанками из-за лимита 8K TPM на Free plan.

**MiniMax M3 через OpenRouter** оставляем как дополнительный резервный вариант: у бесплатного endpoint большой контекст и мультимодальность, однако Free-план OpenRouter ограничен 50 запросами в сутки, а бесплатные endpoints rate-limited.

## Расчёт стоимости одного сценария

Сценарий: загрузка PDF методички (15 страниц, примерно 15000 токенов текста), плюс генерация 5-10 вопросов (примерно 1000 токенов на выходе), плюс разбор 5-10 устных ответов пользователя (каждый ответ и разбор это примерно 300 токенов на вход и 200 на выход, итого около 2500 токенов на всю сессию разборов).

Итого на одну сессию: примерно 15000 (текст методички) + 1000 (вопросы) + 2500 (разборы ответов) = **18500 токенов**.

Для **Qwen3.8 27B локально** стоимость токенов равна **0 рублей**: оплачивается только собственное железо/электроэнергия. Для **Gemini 3.8 Flash** при попадании в Free tier стоимость токенов также **0 рублей**. Для **GPT-OSS 120B через Groq** стоимость токенов **0 рублей** в рамках Free plan, но запросы с длинным контекстом нужно разбивать на части из-за лимита 8K TPM. Для **MiniMax M3 через OpenRouter** стоимость endpoint **0 рублей**, но есть ограничение бесплатного тарифа по числу запросов.

Практически это означает: на раннем этапе North Star по стоимости выполняется у всех четырёх вариантов; главным различием становятся приватность, лимиты и требования к инфраструктуре.

## Что меняется, если модель придётся держать локально

Для бесплатного и приватного варианта рекомендуем заменить старый **Qwen 7B** на **Qwen3.8 27B**. Это более свежая open-weight модель, выпущенная в августе 2026 года, с поддержкой запуска через vLLM/SGLang и OpenAI-совместимого API.

При локальном запуске:

- данные методичек и ответов не обязаны покидать инфраструктуру команды;
- стоимость inference по токенам равна 0 рублей;
- требуется локальное железо, причём итоговые требования сильно зависят от квантования и выбранного runtime;
- для командной эксплуатации нужен либо общий GPU-сервер, либо установка модели у каждого участника.

## Лимиты и деградация

Для бесплатных облачных моделей лимиты считаем частью дизайна системы, а не исключением. Бот должен отслеживать ошибки rate limit и переключаться на fallback.

Рекомендуемый порядок fallback: **Qwen3.8 локально → Gemini 3.8 Flash → GPT-OSS 120B/Groq → MiniMax M3/OpenRouter** в зависимости от наличия локального железа и требований к приватности.

Когда бюджет токенов на сессию или на день исчерпан, бот присылает сообщение "Дневной лимит запросов исчерпан, попробуй завтра" вместо тихого зависания или непонятной ошибки. На лабу 1 это просто зафиксированное поведение в документе, реализация появится когда будет код бота.
