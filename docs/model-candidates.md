# Кандидаты моделей и бюджет

## Кандидаты

Для первой лабы сравниваем три варианта: облачную модель общего назначения, локальную open-weight модель и российскую облачную модель. Для проекта важны работа с PDF и длинным контекстом, удобство подключения к боту, стоимость и ограничения по данным.

| Кандидат | Тип | Подтверждённые характеристики | Ограничения для проекта | Цена и источник |
|---|---|---|---|---|
| [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash) | облачная | Контекст 1 048 576 входных токенов; вход PDF; structured outputs и thinking | Данные передаются внешнему API; Free Tier имеет квоты | [Free Tier — бесплатно; платный ввод $0.75/1 млн токенов и вывод $3.75/1 млн до 31.12.2026](https://ai.google.dev/gemini-api/docs/pricing), то есть $0 за 1000 токенов в пределах Free Tier |
| [Qwen3.5-27B](https://huggingface.co/Qwen/Qwen3.5-27B) локально | локальная, open-weight | Официальная карточка содержит инструкции локального запуска через Transformers, vLLM, SGLang и Docker; контекст по умолчанию 262 144 токена; лицензия Apache-2.0 | Требуются собственные вычислительные ресурсы; карточка рекомендует несколько GPU для максимального контекста, поэтому доступный контекст и скорость зависят от оборудования и квантования | $0 за API-токены при самостоятельном запуске; остаются расходы на оборудование и электричество ([карточка и лицензия](https://huggingface.co/Qwen/Qwen3.5-27B)) |
| [GigaChat-3-Ultra](https://developers.sber.ru/docs/ru/gigachat/models/gigachat-3-ultra) | облачная, российская | Доступна физлицам через API во Freemium; контекст 128 000 токенов | Для физлиц действует один поток; качество на наших методичках требуется проверить экспериментом | $0 в пределах Freemium: для Ultra выделено [50 млн бесплатных токенов на 12 месяцев](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs); ограничение одного потока подтверждено в [документации](https://developers.sber.ru/docs/ru/gigachat/limitations) |

## Выбор на лабу 1

Для лабы 1 выбираем Gemini 3.8 Flash как основную модель.

Она закрывает сценарий одним API и доступна в Free Tier. Нам нужно принимать PDF методички, выделять основные темы, генерировать вопросы для подготовки к защите и разбирать ответы студента. Официальная карточка подтверждает поддержку PDF, контекст 1 048 576 токенов, structured outputs и thinking: [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash). Наличие функций подтверждено источником; вывод о том, что они упрощают MVP, является архитектурной оценкой команды.

Для первой версии это позволяет сделать один API-интеграционный путь и не разворачивать собственный GPU-сервер. Это не характеристика модели из источника, а инженерный вывод из сравнения облачного API с самостоятельным запуском Qwen.

Методички и ответы студентов при использовании облачной модели передаются внешнему API. Поэтому облачный вариант допустим только при отсутствии требования вуза хранить материалы исключительно внутри инфраструктуры команды. Если такое требование появится, основным кандидатом становится локальная [Qwen3.5-27B](https://huggingface.co/Qwen/Qwen3.5-27B), официальная карточка которой содержит варианты самостоятельного запуска.

Итого: Gemini 3.8 Flash — основная модель; Qwen3.5-27B и GigaChat-3-Ultra — резервные кандидаты. Одновременно все три модели в первой реализации не подключаем.

## Расчёт стоимости одного сценария

Рабочая оценка команды для одной сессии:

- PDF методички — около 15 000 входных токенов;
- инструкция и ответы пользователя — около 1 500 входных токенов;
- 5–10 вопросов и разбор ответов — около 2 000 выходных токенов.

Итого: примерно **16 500 входных + 2 000 выходных = 18 500 токенов**. Это внутренний бюджет MVP, а не опубликованная характеристика провайдера; фактический расход будет измеряться по usage-полям API.

Для Gemini 3.8 Flash такая сессия стоит **$0 в пределах Free Tier**. В платном тарифе до 31 декабря 2026 года официальный тариф составляет $0.75 за 1 млн входных и $3.75 за 1 млн выходных токенов: [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing). Расчёт платной сессии:

`16 500 × 0.75 / 1 000 000 + 2 000 × 3.75 / 1 000 000 = $0.019875`, то есть примерно **$0.02**.

Для [Qwen3.5-27B](https://huggingface.co/Qwen/Qwen3.5-27B) при самостоятельном запуске нет оплаты API-токенов, но есть расходы на оборудование и электричество. Для GigaChat-3-Ultra стоимость равна $0 в пределах Freemium; официальный тариф выделяет Ultra [50 млн бесплатных токенов на 12 месяцев](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs).

Следовательно, все три кандидата позволяют провести первые эксперименты без платы за токены в пределах своих условий. Выбор Gemini сделан не только по цене, но и по наличию PDF-входа и большого контекста, подтверждённых его официальной карточкой.

## Что меняется, если модель нужно держать локально

Если вуз или команда потребуют не отправлять методички и ответы во внешний API, переходим на [Qwen3.5-27B](https://huggingface.co/Qwen/Qwen3.5-27B) локально.

Для проекта это означает:

- материалы можно обрабатывать внутри собственной инфраструктуры;
- отсутствует плата внешнему API за токены;
- требуется компьютер или сервер с подходящим GPU;
- необходимо настроить локальный сервер модели и API для команды;
- скорость и доступная длина контекста зависят от оборудования и квантования.

Возможность локального запуска и требования для максимального контекста подтверждены [официальной карточкой Qwen3.5-27B](https://huggingface.co/Qwen/Qwen3.5-27B). Оценка объёма инфраструктурной работы является выводом команды.

## Лимиты и деградация

Gemini 3.8 Flash имеет [Free Tier с квотами](https://ai.google.dev/gemini-api/docs/pricing), поэтому бот должен явно обрабатывать исчерпание лимита. В первой версии он возвращает сообщение: **«Дневной лимит запросов исчерпан, попробуй завтра»**. Автоматическое переключение на другую модель пока не добавляем, чтобы не менять качество ответов внутри одной сессии.
