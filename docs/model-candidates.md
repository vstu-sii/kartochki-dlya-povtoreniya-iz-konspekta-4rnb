# Кандидаты моделей и бюджет

Расход токенов считаем до старта разработки, чтобы бесплатный лимит или доступный бюджет не закончились посреди спринта.

## Кандидаты

Мы обновили исследование 6 сентября 2026 года. Для нашей лабы смотрим в первую очередь на четыре вещи: можно ли пользоваться моделью бесплатно, насколько хорошо она работает с русским и учебными текстами, насколько удобно подключить её к боту и что будет с данными.

| Кандидат | Тип | Плюсы | Минусы | Цена за 1000 токенов |

| **Qwen3.8 27B локально** | локальная, open-weight | бесплатно после установки, данные остаются внутри нашей инфраструктуры, можно запускать через совместимые локальные рантаймы | нужно своё железо, настройка сложнее облачного API, скорость и качество зависят от GPU и квантования | **0 рублей** за токены |

## Выбор на лабу 1

Мы оставляем три варианта и не хотим заранее завязывать весь проект на одну модель.

Основным вариантом для приватного сценария мы считаем **Qwen3.8 27B локально**. Его главное преимущество для нас в том, что конспекты и методички можно не отправлять во внешний сервис. Минус очевидный: нужно железо, а для командной разработки локальный запуск сложнее.

Основным облачным вариантом берём **Gemini 3.8 Flash**. У него бесплатный Free tier, большой контекст, поддержка PDF и structured outputs, поэтому он хорошо подходит под наш сценарий с методичками и генерацией вопросов. По данным Google, у модели контекст до 1 048 576 токенов. citeturn715914search0turn715914search14

Российским запасным вариантом берём **GigaChat-3-Ultra**. Это актуальная модель GigaChat, которая доступна физическим лицам в рамках Freemium-режима. По официальной документации GigaChat сейчас даёт физлицам бесплатные квоты, а для Ultra отдельно указано бесплатное использование в Freemium. citeturn715914search1turn715914search6

## Расчёт стоимости одного сценария

Сценарий: загрузка PDF методички (15 страниц, примерно 15000 токенов текста), плюс генерация 5-10 вопросов (примерно 1000 токенов на выходе), плюс разбор 5-10 устных ответов пользователя (каждый ответ и разбор — примерно 300 токенов на вход и 200 на выход, итого около 2500 токенов на всю сессию разборов).

Итого на одну сессию: примерно 15000 (текст методички) + 1000 (вопросы) + 2500 (разборы ответов) = **18500 токенов**.

Для **Qwen3.8 27B локально** стоимость токенов равна **0 рублей**. Мы платим только за своё железо и электричество.

Для **Gemini 3.8 Flash** стоимость токенов также **0 рублей**, пока мы остаёмся внутри бесплатного тарифа. Важно учитывать, что у бесплатного тарифа есть квоты, поэтому полностью считать его безлимитным нельзя. citeturn715914search3

Для **GigaChat-3-Ultra** стоимость токенов для нас тоже **0 рублей**, пока мы используем доступный физлицу Freemium-лимит. По официальной документации с 1 сентября 2026 года для физлиц действует большой бесплатный пул токенов, в том числе отдельная квота для Pro и другие бесплатные квоты в рамках Freemium. citeturn715914search1turn715914search2

Получается, что для нашей лабы по деньгам все три кандидата подходят. Поэтому главным критерием становится не цена токена, а качество, лимиты и требования к приватности.

## Что меняется, если модель придётся держать локально

Если вуз или команда потребуют не отправлять методички и ответы во внешний API, остаётся локальный вариант **Qwen3.8 27B**.

Для нас это означает:

- данные пользователей и учебные материалы можно хранить внутри нашей инфраструктуры;
- токены не оплачиваются внешнему провайдеру;
- нужен сервер или компьютер с подходящим GPU;
- нужно отдельно настроить запуск модели и API для всей команды;
- качество и скорость будут зависеть от квантования и железа.

Для прототипа это сложнее, чем подключить облачный API, но зато мы не зависим от внешних лимитов и не отправляем учебные материалы наружу.

## Лимиты и деградация

Мы сразу закладываем fallback, потому что у бесплатных облачных моделей есть квоты. Бот должен понимать ошибку rate limit и не зависать.

Для нашей версии можно использовать такой порядок:

**Qwen3.8 локально → Gemini 3.8 Flash → GigaChat-3-Ultra.**

Если локального железа нет, основной порядок будет **Gemini 3.8 Flash → GigaChat-3-Ultra**.

Когда бесплатный лимит или дневная квота закончились, бот присылает сообщение: **«Дневной лимит запросов исчерпан, попробуй завтра»**. Для первой лабы этого достаточно; полноценную автоматическую деградацию между моделями можно реализовать позже.

Также нужно учитывать, что у GigaChat для физлиц действует ограничение по потокам: по официальной документации доступен один поток независимо от того, используются бесплатные или платные токены. citeturn715914search7

## Итог

Мы оставляем три модели:

1. **Qwen3.8 27B** — когда для нас важнее всего приватность и есть железо.
2. **Gemini 3.8 Flash** — основной облачный вариант для быстрого прототипа.
3. **GigaChat-3-Ultra** — российский вариант и запасной облачный API.

Для лабы 1 начинаем с **Gemini 3.8 Flash**, если нет требования хранить данные только внутри нашей инфраструктуры. Если такое требование появляется, переключаемся на **Qwen3.8 27B**. GigaChat-3-Ultra оставляем как российский fallback.
