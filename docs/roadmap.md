# Roadmap и скоуп MVP

## Цель Demo Day

Студент отправляет PDF одной лабораторной в Telegram, получает 5–10 подтверждённых источником вопросов, отвечает текстом, получает обратную связь и видит итог сессии. Команда демонстрирует измеренные качество, задержку и стоимость на golden dataset.

## MVP-скоуп

| Возможность | UC | Критерий готовности |
|---|---|---|
| PDF с текстовым слоем | UC-01, UC-05 | ограничения проверяются до LLM, ошибки понятны |
| 5–10 карточек | UC-01 | JSON Schema + подтверждённая цитата каждой карточки |
| Текстовый ответ | UC-02 | один вопрос за раз, вердикт и пропущенные пункты |
| Оценка полезности | UC-03 | одна актуальная оценка на карточку |
| Прогресс сессии | UC-04 | завершение, итог, продолжение |
| Primary/fallback модель | UC-01, UC-02 | модель и факт fallback видны в telemetry |
| Evals и безопасность | все | golden dataset, регрессия, prompt-injection тесты |

## Явный не-скоуп

- OCR рукописных конспектов и сканов без текстового слоя;
- DOCX, изображения, аудио и ссылки на сайты;
- голосовой ввод/вывод и STT/TTS;
- подготовка ко всему экзамену или работа с несколькими документами;
- RAG, векторная БД, интернет-поиск и многошаговый агент;
- автоматическое редактирование учебных материалов;
- кабинет преподавателя, совместные наборы и публичный каталог;
- мобильное приложение вне Telegram;
- гарантированная педагогическая или фактическая безошибочность.

## Вехи

| Веха | Результат | Выходной критерий |
|---|---|---|
| Лаба 2 — чертежи | UC, C4, ADR, ERD, OpenAPI, DoD, 36 eval-кейсов, threat model, прототип | локальные проверки зелёные; ручные пункты явно отмечены |
| Лаба 3 — MVP | Telegram-бот, PDF parser, AI gateway, БД, CI mini-evals | happy path UC-01/02 работает end-to-end |
| Лаба 4 — production-ready | секреты, лимиты, мониторинг, бэкапы, атаки | threat cases проходят; compose/production health checks зелёные |
| Лаба 5 — метрики | полный eval, latency/cost dashboard, исправления | полезность ≥80%, grounding ≥95%, p95 ответа ≤7 с |
| Лаба 6 — Demo Day | воспроизводимая демонстрация и отчёт | новый PDF → итог сессии без ручных обходов |

## Правила изменения скоупа

Новая функция попадает в MVP только если привязана к боли из `docs/prd.md`, имеет UC и измеримый критерий, а команда явно снимает задачу сопоставимого размера. RAG добавляется только при выполнении условий из `docs/ai-pipeline.md`.
