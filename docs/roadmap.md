# Roadmap и скоуп MVP

Актуальный замороженный скоуп Lab 4 / Demo Day: **`docs/mvp-scope.md`**. Этот файл — обзор вех курса.

## Цель Demo Day

Студент отправляет PDF одной лабораторной в Telegram/Web, получает grounded-вопросы, отвечает текстом, видит разбор и итог сессии. Команда показывает качество, лимиты, мониторинг и CI на живой системе.

## MVP-скоуп (сводка)

| Возможность | UC | Критерий |
|---|---|---|
| PDF ≤10 МБ, текстовый слой / базовый OCR | UC-01, UC-05 | guards до LLM |
| 5–10 карточек без дублей тезисов | UC-01 | schema + grounding |
| Текстовый ответ | UC-02 | verdict + missing points |
| Оценка полезности | UC-03 | одна актуальная оценка |
| Прогресс сессии | UC-04 | resume / TTL |
| Лимиты и cheap tier | UC-06 | 80% / 100% бюджета |
| Model tool | UC-07 | таймаут обработан |
| Evals, CI, security, мониторинг | все | gates + dashboard |

## Явный не-скоуп

См. полный список с причинами в `mvp-scope.md`. Кратко: мульти-PDF, CMS преподавателя, платежи, голос, RAG, Redis-scale, автоправка эталонов, рукописный OCR, полный IdP.

## Вехи

| Веха | Результат | Выходной критерий |
|---|---|---|
| Лаба 2 — чертежи | UC, C4, ADR, OpenAPI, DoD, evals | локальные проверки зелёные |
| Лаба 3 — прототип | живой бот, baseline, первый eval | UC прогнаны, разрывы с владельцами |
| Лаба 4 — production-ready | CI/CD, staging, limits, security, burndown | DoD инфраструктуры + продукта |
| Лаба 5 — метрики | полный dashboard качества | North Star и защитные метрики |
| Лаба 6 — Demo Day | воспроизводимое демо | новый PDF → итог без обходов |
