Актуальный интегрированный тег `v0.5.5-integrated-candidate` (`bc56b605aaa7a9781fefd1bc576eb0d59bb20301`): [release quality gates](https://github.com/vstu-sii/kartochki-dlya-povtoreniya-iz-konspekta-4rnb/actions/runs/40563748484) выполнены успешно. Сырые логи и JSON после прогона находятся в артефакте этого запуска. Ограничения набора ниже сохраняются; это не тест защиты от всех новых атак и не provider-eval.

После исправлений выполнен `python tests/security/run_attacks.py --mode after`: 17/17 сценариев прошли. Состав: 14 заблокированных инъекций, два разрешённых безопасных контроля и один отказ анонимному запросу без раскрытия карточек. Результат: `artifacts/security/lab4-attacks-after.json`.

Три Demo Day-сценария — инструкция в извлечённом тексте PDF, извлечение system prompt через ответ студента и текстовая попытка вызвать удаляющий tool — заблокированы. Runner напрямую вызывает обработчики, транспорт модели подменён. Это проверка текстовых защит и обработчиков, а не загрузка реального PDF по HTTP и не выполнение реального инструмента моделью.

## Остаточные риски

Оценки качественные; зелёный тест на фиксированном наборе не гарантирует защиту от всех вариантов атаки.

| Риск | До контроля | Остаточный риск | Дальнейшее действие |
|---|---|---|---|
| Инъекция через текст | высокий | средний: неизвестные формулировки вне набора | Расширять red-team набор; перед демо пройти сценарий через настоящий интерфейс |
| Подмена identity / чужая сессия | высокий | высокий: X-User-ID сам по себе не аутентификация | Проверенный Telegram login/session token до публичного запуска |
| Необратимое действие модели | высокий | средний: проверены ограничения и контракт, не все интеграции | Сохранять авторизацию действий на стороне приложения |
| Перерасход токенов | средний | средний: лимиты не доказывают точность фактических расходов | Сверять учёт с провайдером и наблюдать алерты |
| Вредоносный бинарный PDF/OCR | не оценён тестами | потенциально высокий, не измерен | Отдельные parser/OCR fuzzing и ограничения ресурсов |

Ограничения остаются открытыми; отчёт не подтверждает безопасность публичной эксплуатации с полноценной изоляцией пользователей.
