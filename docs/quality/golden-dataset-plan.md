# План golden dataset

## Источник примеров

30-50 пар "вход и эталон" собираем из реальных методичек по лабораторным работам участников команды (свои же предметы, чтобы было легко проверить качество вручную).

Формат одной пары: фрагмент текста методички, ожидаемый тезис, ожидаемый вопрос, эталонный короткий ответ.

## Происхождение и версия данных

Берём только собственные методички команды и открытые методические материалы вуза, ничего чужого без разрешения. Версионируем датасет файлом с датой в названии, чтобы можно было откатиться если испортим данные.

## Формат записи

CSV или jsonl со столбцами: `source_pdf`, `fragment_text`, `expected_thesis`, `expected_question`, `expected_answer`.

## Владелец датасета

Quality & Safety ведёт файл, обновляет по мере появления новых примеров, следит чтобы формат не расползался.
