# Security report v1 — измерение исторической проверки входа

Дата перепроверки: 16.10.2026.

```bash
python tests/security/run_attacks.py --mode before --output artifacts/security/lab4-attacks-before.json
```

Runner читает через git show реальный `backend/quality_guards.py` из коммита
`0dea82a452586c49404778cb43806d2aba9b5329`, загружает этот модуль и вызывает
validate_untrusted_input для каждой записи attacks.jsonl.
При недоступной истории команда падает, константного результата вместо измерения нет.
CI использует fetch-depth: 0. Артефакт содержит SHA коммита, хеш кода и хеш набора.

## Результат и предел интерпретации

13/13 записей допущены исторической функцией: 11 подозрительных текстов и два контроля.
13/13 совпадений с expected_before означает воспроизведение ожидаемого поведения старого
фильтра, а не безопасную работу системы.

Это измерение допуска текста. Не проверялись успешное раскрытие system prompt,
манипуляция оценкой и иное поведение прежней модели. Старый отчёт с константой allow
не является экспериментальным доказательством эксплуатации и заменён этим прогоном.
