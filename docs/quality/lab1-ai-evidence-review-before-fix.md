## Принятое правило оценки

- Ложный пропуск уже названного понятия считается нарушением no_contradiction.
- Общая фраза с обрезанными словами вместо объяснения обязательных смыслов не засчитывается как mandatory_points_complete.
- Если студент дал полный правильный ответ и система правильно засчитала его без ложных пропусков, достаточно краткого подтверждения; заново пересказывать верный ответ не требуется.
- Тон оценивался отдельно от фактической правильности и полноты; ни в одной строке участницы не подтвердили нарушения тона.

## Замечания и решения

| Строки | Подтверждённое решение |
|---|---|
| REV-001, REV-009, REV-018 | Ложные пропуски «памят», «разделяют», «одног»: соответствующий смысл уже есть в ответе. no_contradiction=false, полнота=false. |
| REV-012 | Проверяющие признали снижение оценки необоснованным по записанному mandatory_points: TLS-защита данных названа. no_contradiction=false, полнота=false. |
| REV-015 | Проверяющим не хватает явного названия FIFO, поэтому они приняли partially_correct. Это дополнительное ожидание отсутствует в текущем mandatory_points; несогласованность критерия записана явно. no_contradiction=true, полнота=false, поскольку система указала пропуск «принцип», а не FIFO. Dataset не изменяли. |
| REV-002, REV-003, REV-005, REV-006, REV-008, REV-013, REV-016, REV-019 | Оценка не противоречит ответу, но объяснение пропусков/ошибок неполно и содержит обрезанные слова. no_contradiction=true, полнота=false. |
| REV-004, REV-007, REV-010, REV-011, REV-014, REV-017, REV-020 | Оценка и учёт обязательных пунктов признаны корректными. no_contradiction=true, полнота=true. |

Требование назвать FIFO уточнено в ходе обсуждения REV-015; это ограничивает сопоставимость данной строки с исходной рубрикой. При следующем независимом прогоне требование к термину нужно согласовать до разметки. Исходные expected_verdict и mandatory_points в этом ревью не переписывались.

## Воспроизведение подсчёта

```powershell
python tests/evals/audit_lab1_evidence.py
```

Аудитор проверяет согласованность исходных полей с dataset, повторяет технические результаты и независимо пересчитывает ручные метрики. `artifacts/evals/lab1-ai-evidence-audit.json` содержит `human_review_completed_rows=20`, ручные метрики и отдельные флаги достижения целей. Код завершения 0 подтверждает техническую согласованность артефакта, а не достижение ручных целей.

После исправлений AI необходим новый результат системы и повторное ревью. Оценки текущего снимка нельзя менять только ради порога.
