## Обнаруженные отклонения

- AI-MANUAL-01 (AI, Product): фрагменты одного предложения методички превращаются в отдельные незаконченные вопросы. Примеры: «…настройку сети и получить» (2), «…командами Linux для управления» (5). Проверять полноту смыслового тезиса после извлечения текста.
- AI-MANUAL-02 (AI, Quality): feedback содержит лексические обрезки «настройк», «получ», а в правильном ответе советует упомянуть «цель». Нужны понятные содержательные пояснения.

Эти наблюдения не меняют эталоны mutex/индекс/ROLLBACK: это отдельные кейсы и отдельное подтверждение команды.
