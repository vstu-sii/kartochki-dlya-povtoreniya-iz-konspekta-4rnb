# Короткое объяснение цифр baseline на приёмке

Baseline доказал работоспособность полного контура, но **не** готовность заявлять облачное качество Gemini как измеренное.

- **Schema pass rate 100%** — UI стабильно получает контракт.
- **Grounded-card rate 100%** — цитата карточки действительно взята из документа.
- Эти две цифры подтверждают интеграцию и grounding, но не полезность формулировок (см. AI-MANUAL-01/02 из ручного прохода Постернака Дениса).

**Agreement проверки ответов = 90,48%** на воспроизводимом deterministic fallback и **превышает порог прототипа 85%**. Четыре расхождения из 42 остаются видимыми: один краткий правильный ответ оценён как частичный, три почти дословных ответа конфликтуют с эталонной меткой `partially_correct`. Следующий шаг — ручное ревью этих эталонов и **отдельный** измерительный прогон Gemini на том же наборе.

**p95 ≈ 2–3 мс** относится только к локальному детерминированному baseline. Его нельзя переносить на Gemini и публичную сеть. Ценность — быстрый воспроизводимый CI без секретов. Облачные latency и стоимость команда примет только после прогона с ключом и выгруженным артефактом (спринт 4, P0).

## Итоговое продуктовое решение

1. Интеграционный контур сохраняем.
2. Локальный baseline оставляем как fallback и средство CI.
3. Пользовательское доверие к **облачному** review не заявляем, пока нет сохранённого Gemini-прогона ≥85% agreement на том же golden dataset.
4. 90,48% deterministic — достаточное основание закрыть DoD Lab 3 по «цифры baseline объяснены», но недостаточное для Demo Day как «модель готова».
