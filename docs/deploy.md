# Деплой

## Прод URL

https://kartochki-dlya-povtoreniya-iz-konspekta.onrender.com/

## Куда деплоим

Render.com, бесплатный тариф.

## Как задеплоить

1. Зарегистрироваться на render.com через GitHub аккаунт
2. Создать новый Web Service, выбрать этот репозиторий
3. В настройках указать Environment: Docker, путь к Dockerfile: корень репозитория (`Dockerfile`)
4. Нажать Deploy, дождаться сборки образа
5. Скопировать выданный публичный URL вида `https://имя-сервиса.onrender.com`
6. Проверить что страница открывается у другого члена команды с другого устройства, не только у того кто деплоил

## Кто может передеплоить

Пока только Delivery, доступ к Render у него один. Если бесплатный тариф Render не подойдёт по лимитам (например сервис засыпает при простое), запасной вариант Railway.app с похожим бесплатным тарифом.

## Что дальше

В лабе 2-3, когда появится реальный backend с ботом, этот же процесс деплоя переиспользуем, просто Dockerfile соберёт уже настоящее приложение, а не hello-world заглушку.
