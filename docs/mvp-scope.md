# Зафиксированный MVP к Demo Day

Скоуп заморожен **19.09.2026**. Изменение только обменом: новый пункт после удаления равного или большего объёма. Канон UC: `docs/use-cases/README.md`. PRD: `docs/prd.md`.

## Входит

- Telegram-бот и web принимают **один** PDF до **10 МБ** и **40** страниц (UC-01, UC-05).
- Основной путь — PDF с текстовым слоем; **базовый OCR** читаемых печатных сканов поддерживается как в Lab 3.
- Система создаёт **5–10** grounded-карточек (допускается меньше при нехватке тезисов, без дублей) (UC-01).
- Ответ своими словами → verdict, объяснение, missing points; эталон только из БД (UC-02).
- Оценка полезности и история событий; модель не пишет рейтинг сама (UC-03).
- Прогресс сессии сохраняется; resume по владельцу; TTL 30 дней (UC-04).
- Суточные лимиты: ≤50 model requests и ≤120k токенов; после **80%** — дешёвая модель; при **100%** — отказ (UC-06).
- Model tool с контрактом, таймаутом и отказом (UC-07).
- CI: тесты + полный eval; merge в `main` → деплой.
- Staging из того же Compose-контура, что production.
- Grafana: HTTP-метрики, логи, LLM-трейсы, срабатывания бюджета.
- Prompt injection из известного набора блокируется **кодом**.

## Явный не-скоуп (с причинами)

| Вырезано | Причина |
|---|---|
| Подготовка сразу по нескольким PDF | Смешение источников ломает проверяемый grounding |
| Редактор карточек преподавателем | Demo Day проверяет автоматический путь, не CMS |
| Платежи и подписки | Нет доказанного удержания; платёжный контур даёт непропорциональный риск |
| Голосовые ответы / STT | Отдельная стоимость и ошибки распознавания |
| Полнотекстовый RAG по библиотеке | Один PDF помещается в контекст; выгода поиска не доказана |
| Redis / горизонтальный limiter | Один production-инстанс; интерфейс limiter готов к замене (долг `L4-D-01`) |
| Автоправка спорных эталонов | Golden меняется только после ручного ревью |
| **OCR-нагрузка на сложных/рукописных сканах** | Вырезано 02.10 (день 13 burndown): объём измерения и тюнинга OCR не укладывался в Demo Day; рукопись вне продукта |
| Серверная auth production-уровня сверх `X-User-ID` | Достаточно для прототипа курса; полный IdP — следующий спринт |
