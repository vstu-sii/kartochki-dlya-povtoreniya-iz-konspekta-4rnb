# Lab 3: цифры baseline и выводы

## Как воспроизвести

```bash
python tests/evals/run_evals.py --output artifacts/evals/baseline-results.json
```

Команда не требует сети и ключа. Она читает frozen JSONL, вызывает тот же `BaselineModel`, который доступен через API, пишет результаты, latency, токены и отдельный trace-файл. Ноутбук `notebooks/lab3_baseline.ipynb` выполняет эту же команду и читает артефакт, поэтому цифры не остаются только в выводе ячейки.

## Зафиксированный прогон 14.10.2026

- dataset содержит 128 уникальных кейсов;
- реально выполнены 95 модельных (`generate_card`/`review_answer`), 33 API/DB-кейса явно пропущены;

Источник истины: `artifacts/evals/baseline-results.json`. Числа в документе округлены.

## Что означают цифры для продукта

Baseline доказывает техническую концепцию для выполненных модельных операций: структура стабильна, цитаты проверяемы, ответы проходят модельный путь и трассируются. После нормализации русских слов, формул, распространённых перефразирований и явных противоречий согласие review превысило порог 85%. Четыре расхождения из 42 сохранены в отчёте и не скрыты средней метрикой. Локальную latency нельзя выдавать за latency Gemini, а `SAFE`/`UX`/`STATE` требуют отдельного API/DB E2E.

Решение: сохранить deterministic baseline как дешёвый CI fallback. Для пилота
подключён `gemini-3.8-flash`: она формирует до пяти независимых grounded-карточек
и проверяет смысл свободного ответа, принимая синонимы и пересказ. Облачные цифры
нельзя подменять локальными: перед расширением пилота Gemini прогоняется на том же
наборе и принимается только при agreement review ≥85%, grounding ≥95%, p95 review
≤7 секунд и стоимости ≤$0.04 за сессию. Оставшиеся расхождения эталонов проверяет
человек; их нельзя автоматически переписывать под модель.

## Retry, fallback и трассировка

При `MODEL_PROVIDER=gemini` выполняется до трёх попыток с увеличивающейся паузой
для 429/5xx и сетевых сбоев; после неуспеха или нарушения JSON Schema используется
grounded deterministic fallback. Генерация дополнительно отклоняется, если цитата
не найдена на заявленной странице или вопросы повторяются. В ответе фиксируются
`model`, `fallback_used`, `trace_id`, latency и фактический usage провайдера.

Каждый вызов записывается SDK `ml/tracing/client.py`; dashboard доступен на порту
3000. При `TRACE_CONTENT=false` в трассе остаются хеш, длина, usage, verdict и
число карточек, но не текст PDF и ответа. Ключ читается только из
`GEMINI_API_KEY`. Бесплатный тариф подходит для демо и ограниченного пилота;
для приватных коммерческих документов нужен режим обработки данных, согласованный
с владельцем продукта и условиями провайдера.
