# Глоссарий команды

Термины из предметной области продукта, согласовать вслух со всей командой. Список пополняется весь курс.

| Термин | Определение |
|---|---|
| Конспект | Исходный документ пользователя: методичка или запись лекции в PDF, из которого бот вытаскивает материал |
| Тезис | Один ключевой пункт из конспекта, вокруг которого строится вопрос для повторения |
| Карточка | Пара вопрос-ответ, сгенерированная на основе тезиса, базовая единица повторения |
| Устный раунд | Один цикл: бот задаёт вопрос, пользователь отвечает голосом или текстом, бот даёт обратную связь |
| Разбор ответа | Сверка ответа пользователя с эталонным тезисом и объяснение чего не хватает |
| Сессия | Один заход пользователя в бота от загрузки PDF до завершения серии устных раундов |
| Защита лабы | Устный опрос преподавателем по теории лабораторной работы, целевое событие, к которому готовится пользователь |
| Эталонный ответ | Короткая формулировка правильного ответа на вопрос, с которой сравнивается ответ пользователя |
| Golden dataset | Набор проверенных вручную пар вход-эталон, на которых меряем качество системы |
| North Star | Главная метрика продукта, показывающая что он реально решает боль пользователя |
| Prompt injection | Попытка через содержимое загруженного PDF заставить модель нарушить заданные инструкции |
| Токен-бюджет | Ограничение по количеству токенов LLM на один запрос или сессию, чтобы не выйти за рамки затрат |
| STT | Speech to text, распознавание голосового сообщения пользователя в текст |
| DoD | Definition of Done, список проверяемых критериев готовности артефакта |
| ADR | Architecture Decision Record, запись про выбор технического подхода с указанием цены решения |

Список неполный, дополнять по ходу разработки, когда появляются новые термины в коде и в use case.
