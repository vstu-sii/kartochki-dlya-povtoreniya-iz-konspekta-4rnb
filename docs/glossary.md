# Глоссарий команды

Единый словарь предметной области, архитектуры и AI-пайплайна. Lab 4: лимиты, tool, North Star v3.

| Термин | Определение |
|---|---|
| Конспект | PDF методички или лекции, из которого система извлекает материал |
| Тезис | Ключевой пункт конспекта, вокруг которого строится вопрос |
| Карточка | Пара «вопрос — эталон» со страницей и цитатой |
| Раунд вопрос–ответ | Вопрос → текстовый ответ → verdict и feedback |
| Разбор ответа | Сверка с эталоном и список пропущенных пунктов |
| Сессия | Заход от загрузки PDF до завершения или сохранения прогресса |
| Защита лабы | Устный опрос преподавателя по теории лабораторной |
| Эталонный ответ | Краткая правильная формулировка для сравнения |
| Golden dataset | Версионируемый набор «вход — эталон» для evals |
| North Star | Доля начатых сессий, завершённых ≥5 карточками (цель ≥70%, см. `prd.md`) |
| Полезность карточки | Доля оценок «Полезно»; вспомогательная UX-метрика |
| Prompt injection | Попытка через PDF/ответ заставить модель нарушить инструкции |
| Токен-бюджет | Суточный лимит токенов/запросов на пользователя |
| Cheap tier | Дешёвая модель после 80% суточного бюджета |
| DoD | Definition of Done — проверяемые критерии готовности |
| ADR | Architecture Decision Record с полем «Цена решения» |
| AI gateway | Единая точка к LLM; primary/fallback и нормализация ошибок |
| Primary model | Основная модель штатного сценария |
| Fallback model | Резервная модель при timeout / 429 / 5xx |
| Structured output | JSON по схеме, не свободный текст |
| Grounding | Опора карточки на страницу и дословную цитату |
| Source quote | Дословная цитата со страницы PDF |
| Контекст модели | Данные одного вызова модели |
| Контекстный guard | Проверка входа до вызова модели |
| Prompt / schema version | Версии промпта и формата ответа для evals |
| Repair-вызов | Один повтор генерации при машинной ошибке формата/grounding |
| Idempotency key | Ключ, запрещающий дубликат результата и повторное списание бюджета |
| Trace ID | Сквозной id запроса без содержимого PDF и ответов |
| Card set | Набор 1–10 карточек (цель 5–10) из одного документа |
| Answer review | Verdict + feedback + missing points |
| Text layer | Машиночитаемый текст в PDF |
| OCR | Базовое распознавание читаемых печатных сканов; рукопись и сложные сканы вне MVP |
| Card rating event | Событие изменения оценки полезности |
| Model tool | Инструмент модели с контрактом, таймаутом и минимальными правами |
| Burndown | График оставшихся SP спринта |
| C4 Context / Container | Диаграммы границы системы и контейнеров |
| ACL | Anti-corruption layer к внешнему API |
| Evals | Воспроизводимые проверки AI на golden dataset |
