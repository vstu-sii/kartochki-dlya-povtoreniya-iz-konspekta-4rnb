# Финальные метрики AI на релизе `v0.5.1`

## Проверка ускорения 27.10.2026

Для `gemini-3.5-flash-lite` проверен уровень `minimal` на production SHA `b959a4a4d02976885156b5b8655b4a9e0bb2ce6b`: три полных сценария и 15 разборов завершены без fallback, четвёртая генерация переключилась на fallback `gemini_invalid_output`; пятый сценарий не выполнялся. Медиана разбора 3,266 с, p95 nearest-rank 29,070 с (n=15). [Сохранённые результаты](../artifacts/quality/lab5-production-final/gemini-minimal-b959.json). Порог ≤7 с не достигнут; поскольку прогоны небольшие и выполнены в разное время, это не контролируемое доказательство, что один режим всегда быстрее другого. Решение: режим `minimal` не считать подтверждённой оптимизацией, вернуть `low` и повторно измерить после интеграции `cards-v2.2`. Исторические прогоны нельзя переносить на новую версию промпта как её измерение.

Генерация p95 3,757 с (n=2), разбор p95 9,414 с (n=10), nearest-rank. Порог ≤7 с для разбора не достигнут в этой выборке. [Вызовы и usage](../artifacts/quality/lab5-production-final/gemini-formula-bc56.json). Автоматическое качество deterministic нельзя выдавать за качество Gemini; для устойчивых выводов требуется больший набор и ручная оценка.

Суммарно 4215 входных и 1524 выходных токена, включая опубликованные провайдером thinking tokens. Оценка стандартного платного тарифа — $0.0050745 за два сценария, $0.0025332 и $0.0025413 по отдельности, ниже бюджета $0.04 за сценарий. Это расчёт по usage, а не подтверждение счёта; Free tier может не начислять оплату. При повторной попытке валидатор записывает отклонённый вызов в отдельный trace. [Тарифы Google](https://ai.google.dev/gemini-api/docs/pricing). Малый объём и бесплатные лимиты остаются ограничениями.

Источник истины — JSON-артефакты, документ только объясняет их. Локальные миллисекунды измеряют код fallback и не заменяют latency Gemini. Для B p50 рассчитан как медиана, p95 — методом nearest rank по 20 вызовам этого варианта. Выбран B из-за +5 п.п.; цена выбора — +2537 токенов (+66%). На использованном бесплатном Gemini tier денежное списание равно $0, но токены остаются ресурсом квоты. Для продукта это означает более надёжную смысловую оценку ценой большей квоты и примерно 6,57 с p95, поэтому fallback и бюджетный tier сохранены.

Поэлементная ablation подтверждает вклад каждого механизма: aliases −4,76 п.п. при отключении, stemming −2,38 п.п., source precision −2,38 п.п., contradiction guard −4,76 п.п. Полный результат и строки по кейсам: `artifacts/experiments/lab5-ablation-results.json`.
