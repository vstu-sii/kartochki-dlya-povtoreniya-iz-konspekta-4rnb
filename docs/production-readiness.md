# Готовность Telegram-бота к пилоту и продажам

## Что уже реализовано

- Telegram webhook на HTTPS и локальный long polling;
- текстовые PDF и OCR русско-английских сканов;
- лимиты 10 МБ, 40 страниц и ограничение размера контекста;
- grounded-карточки: страница и дословная подтверждающая цитата;
- Gemini с JSON Schema, повторными попытками и локальным fallback;
- смысловая проверка свободного ответа: синонимы и пересказ принимаются;
- PostgreSQL в Compose, миграции, сохранение карточек, ответов, прогресса и оценок;
- health checks, CI и сквозная проверка UI → API → модель → БД;
- секреты только через окружение; содержимое PDF скрыто в трассах по умолчанию;
- понятные сообщения об ошибках и команды `/new`, `/status`, `/help`, `/privacy`, `/cancel`.

## Настройка Render для пилота

1. В существующем Web Service выбрать ветку `lab3-delivery-prototype`.
2. В Environment добавить секреты `TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY` и
   `DATABASE_URL` управляемого PostgreSQL. Для временной демонстрации без URI
   приложение использует SQLite, но её данные на Render не гарантированно сохраняются.
3. Убедиться, что `MODEL_PROVIDER=gemini`, `LLM_PRIMARY_MODEL=gemini-3.8-flash`,
   `TRACE_CONTENT=false`, `OCR_LANGUAGES=rus+eng`.
4. Выполнить Manual Deploy и проверить `/health`.
5. В Telegram выполнить `/new`, отправить текстовый PDF и скан, ответить своими
   словами, пройти набор до сообщения о завершении и снова вызвать `/start`.

## Обязательно перед платными продажами

- подключить управляемый PostgreSQL вместо временного SQLite Render и включить backups;
- перейти на оплачиваемый Gemini для приватных данных и согласовать регион хранения;
- опубликовать политику конфиденциальности, оферту, сроки хранения и удаление данных;
- добавить согласие пользователя перед отправкой PDF внешнему AI-провайдеру;
- включить per-user rate limit, квоты тарифа и защиту от массовой загрузки;
- настроить мониторинг ошибок/latency, алерты и журнал административных действий;
- добавить команду удаления пользовательских данных и регламент поддержки;
- провести нагрузочный тест, security review и ручную оценку качества на реальных PDF;
- проверить права на учебные материалы и требования закона для целевых стран.

Бесплатный тариф Gemini удобен для учебного демо и ограниченного пилота, но не
является гарантией неограниченной доступности. В бесплатном тарифе Google может
использовать отправленный контент для улучшения продуктов; для конфиденциальных
или коммерческих материалов это должно быть отражено в согласии либо исключено
переходом на подходящий оплачиваемый режим.
