# North Star — завершение учебной сессии

**Метрика:** доля начатых сессий, в которых пользователь завершил минимум пять карточек.

```text
completed_5_rate = sessions(current_position >= 5) / sessions(created_at in period)
```

**Цель PRD v3:** ≥70%. Канонический способ — серверные записи `study_sessions`, условие только `current_position >= 5`; флаг `completed` не используется, потому что техническое завершение возможно раньше. Тестовые аккаунты команды исключаются, период фиксируется в UTC.

## Фактический замер для релиза `v0.5.0`

В production пока нет read-only аналитического экспорта `study_sessions`, поэтому для первого замера использован заранее описанный резервный способ: наблюдаемый внешний прогон с тем же условием «не менее пяти карточек». Причина изменения способа — отсутствие безопасного аналитического доступа к production-БД; клики команды не засчитываются.

28.09.2026 одна из одной внешней сессии завершила пять карточек: **1/1 = 100%** против цели **70%**, разница **+30 п.п.** Формально цель достигнута, но выборка **n=1 недостаточна**. Статус: *измерена, но статистически не подтверждена*. Исходная запись и формула лежат в `artifacts/product/north-star-measurement.json`. Для Demo Day требуется минимум 10 внешних сессий; при 7/10 и выше цель подтверждается.

Защитные метрики: grounding 100%, review agreement ≥85%, доля «Полезно», p95 provider latency и стоимость сессии. Рост North Star нельзя покупать галлюцинациями или скрытыми ошибками.
