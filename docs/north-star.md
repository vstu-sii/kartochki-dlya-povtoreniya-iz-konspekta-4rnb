# North Star — завершение учебной сессии

**Метрика:** доля начатых сессий, в которых пользователь завершил минимум пять карточек.

```text
completed_5_rate = sessions(current_position >= 5) / sessions(created_at in period)
```

**Цель PRD v3:** ≥70%.  
**Канонический способ (PRD):** серверные записи `study_sessions`, условие только `current_position >= 5`; флаг `completed` не используется. Тестовые и командные аккаунты исключаются; период в UTC.

## Смена способа замера (зафиксирована)

В production нет безопасного read-only экспорта `study_sessions` для Product. Поэтому для Lab 5 / релиза `v0.5.1` использован **заранее описанный резервный способ**: наблюдаемый внешний прогон с тем же условием «≥5 карточек», без кликов команды.

Причина: нет аналитического доступа к production-БД. Как только появится экспорт — вернёмся к каноническому SQL-запросу без смены определения метрики.

## Вывод для Demo Day

Формально цель ≥70% на доступной выборке достигнута (100% при n=1). Для устойчивого утверждения «пользовательская ценность доказана» нужен P0 из `acceptance.md`: ≥10 внешних сессий, порог подтверждения ≥7/10. Защитные метрики (grounding 100%, review ≥85%) нельзя жертвовать ради роста North Star.
