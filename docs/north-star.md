# North Star — завершение учебной сессии

**Метрика:** доля начатых сессий, в которых пользователь завершил минимум пять карточек.  
**Цель PRD v3:** ≥70%.

## Способ замера — как записано в PRD

Источник — серверные записи `study_sessions`; прогресс пишется backend при каждом продвижении (`current_position`), а не «со слов пользователя»:

```text
completed_5_rate = sessions(current_position >= 5) / sessions(started in period)
```

Когорта — только внешние пользователи; командные и smoke-аккаунты исключены. Период в UTC. Воспроизводимый расчёт: `scripts/measure_north_star.py` по экспорту `artifacts/product/north-star-sessions-export.json`; машиночитаемый результат: `artifacts/product/north-star-measurement.json`.

**Что изменилось в доступе к данным (не в определении метрики):** прямого read-only аналитического экспорта production-БД у Product пока нет, поэтому запись внешней сессии Дениса перенесена в экспорт из протокола наблюдателя. Сама сессия создавалась и продвигалась через backend (`study_sessions`), а smoke-прогон на проде дополнительно подтвердил тот же серверный путь. Определение, формула, когорта и порог не менялись.
