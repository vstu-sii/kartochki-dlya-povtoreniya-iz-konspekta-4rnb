# North Star — завершение учебной сессии

**Метрика:** доля начатых сессий, в которых пользователь завершил минимум пять карточек.

```text
completed_5_rate = sessions(current_position >= 5 or completed_at != null) / sessions(created_at in period)
```

**Цель PRD v3:** ≥70%. Считаем серверные записи `study_sessions`, а не клики интерфейса; тестовые аккаунты команды исключаем. Период фиксируется в UTC, одна сессия считается один раз.

## Фактический замер release candidate

В доступном ручном внешнем прогоне 28.09.2026 одна из одной начатых сессий прошла пять карточек/UC: **1/1 = 100%**. Формально цель достигнута, но выборка **n=1 недостаточна** для продуктового вывода. Поэтому честный статус — *технически измерена, статистически не подтверждена*. Для Demo Day собираем минимум 10 внешних сессий; при 7/10 и выше подтверждаем цель.

Защитные метрики: grounding 100%, review agreement ≥85%, доля «Полезно», p95 provider latency и стоимость сессии. Рост North Star нельзя покупать галлюцинациями или скрытыми ошибками.
