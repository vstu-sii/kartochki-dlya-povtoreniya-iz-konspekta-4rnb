# Доступ и повтор запросов Lab4

`POST /v1/ai/card-sets` проверяет наличие `X-User-ID` до поиска сохранённого результата. Idempotency scope включает переданный идентификатор пользователя, операцию, клиентский ключ и версию generation prompt; fingerprint включает всё содержимое запроса.

- тот же пользователь + тот же ключ + то же содержимое возвращает прежний набор;
- тот же пользователь + тот же ключ + изменённое содержимое возвращает `409 IDEMPOTENCY_CONFLICT`;
- другой пользователь с тем же ключом получает собственный результат и не видит чужой;
- отсутствие identity возвращает `401 USER_ID_REQUIRED` до model call;
- PDF-путь использует hash документа, а generation version получает через `/v1/model/metadata`.

Ограничение: `X-User-ID` — переданный клиентом идентификатор, а не криптографически подтверждённая аутентификация. Для production его должен устанавливать доверенный Telegram/web adapter после проверки сессии или подписи.
