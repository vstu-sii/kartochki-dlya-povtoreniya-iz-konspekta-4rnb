## North Star

Замер способом из PRD (`study_sessions`, `current_position >= 5`, внешние только): **1/1 = 100% против цели 70% (+30 п.п.)**. Сессия Дениса создана и продвигалась через backend; расчёт — `scripts/measure_north_star.py`, результат — `artifacts/product/north-star-measurement.json`, протокол — `docs/use-cases/validation-lab5.md`. n=1 — статистически не подтверждено.

## После демо (не блокирует показ)

| Работа | Владелец | Почему не в демо-план |
|---|---|---|
| Redis limiter, проверенная auth | Delivery | нужно для массовой продажи, не для сценария Demo Day |
