## Каждая боль из PRD

| Боль | Статус | Живой пример / свидетельство | Остаток |
|---|---|---|---|
| Долго превращать PDF в вопросы | закрыта | публичный UC-01: API вернул 201 и 5 карточек; CardSet сохранён | сложные сканы зависят от OCR |
| Нельзя проверить ответ своими словами | частично | публичный UC-02 вернул `correct`; review agreement Lab5 92,86% | три спорных deterministic-кейса; Gemini выборка мала |
| Неясно, откуда взят ответ | закрыта | карточка показывает страницу и дословную цитату; grounding 100% | для полного контекста нужен исходный PDF |
| Прогресс теряется | закрыта | публичный UC-04 сохранил позицию 5 и восстановил её отдельным GET | очистка записей старше 30 дней отложена |
| Ошибка файла непонятна | частично | публичный UC-05 отклоняет недоверенный документ HTTP 422 с кодом `PROMPT_INJECTION_BLOCKED`; неверный MIME также имеет стабильный код | плохие/рукописные сканы не гарантированы |

Публичная автоматизированная проверка 19.10.2026 прошла целиком: UC-01…UC-05 дали ожидаемые статусы, включая модельную проверку, рейтинг и реальное восстановление прогресса из БД. Машиночитаемое свидетельство — `artifacts/product/lab5-prod-uc.json`; ручной внешний прогон — `docs/use-cases/validation.md`.

UC-06 и UC-07 проверены на неизменяемом теге `v0.5.0` полным integration gate: бюджет переходит на cheap tier при 80%, возвращает стабильный `429 TOKEN_LIMIT_EXCEEDED` при исчерпании; read-only tool имеет success/forbidden/empty/error/timeout и безопасный fallback. [Tagged quality gate завершился success](https://github.com/vstu-sii/kartochki-dlya-povtoreniya-iz-konspekta-4rnb/actions/runs/39175400930). Эти две проверки не выдаются за публичный destructive-canary: исчерпывать реальную пользовательскую квоту на prod намеренно не стали.
